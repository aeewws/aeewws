# aeewws

I build Android-first and terminal-adjacent tools with a focus on mobile AI workflows, Termux bridges, and practical developer utilities.

## Featured Projects

- [codex-mobile](https://github.com/aeewws/codex-mobile) - Mobile-first Android shell for a real local Codex runtime in Termux.
- [termux-codex-keeper](https://github.com/aeewws/termux-codex-keeper) - Watchdog and recovery helper for keeping Codex app-server alive on Termux.
- [tool-schema-fixer](https://github.com/aeewws/tool-schema-fixer) - CLI for normalizing generic tool schemas into OpenAI, Anthropic, and Gemini-friendly shapes.
- [awesome-local-ai-android](https://github.com/aeewws/awesome-local-ai-android) - Curated list of Android-first local AI apps, runtimes, Termux tools, and mobile coding workflows.
- [antigravity-login-fix](https://github.com/aeewws/antigravity-login-fix) - Windows helper for repairing login issues in Google Antigravity installs.

## Focus Areas

- Android + Termux workflow tooling
- Mobile-first AI coding UX
- Local runtime reliability and recovery
- Developer CLI and schema compatibility tools
